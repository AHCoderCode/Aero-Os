# AeroOS customization

AeroOS includes a Control Center so common desktop changes do not require terminal commands.

## Open the Control Center

- Double-click **Settings** on the desktop, or
- Open the Aero menu and choose **AeroOS Control Center**.

## Appearance and accent colors

Open **Theme and accent color** and select one of six presets:

- Aero Dark - Blue
- Aero Dark - Violet
- Aero Dark - Teal
- Aero Light - Blue
- Aero Light - Violet
- Aero Light - Teal

The selection changes the GTK theme, Papirus icon theme and AeroOS accent palette. It is saved in your home directory and remains with full USB persistence. Already-open applications may need to be closed and reopened to use the new GTK colors.

## Wallpaper and desktop icons

Open **Wallpaper and desktop icons**. Use the Desktop settings dialog to choose an image file, adjust its placement and change desktop icon visibility and size. You can use an image saved in your home folder or on another drive.

## Taskbar and Start menu

Open **Taskbar and Start menu** to change panel position, size, appearance, items and launchers. The initial layout uses a centered Docklike taskbar and Aero menu. Changes are saved by Xfce in your user profile.

## Display, keyboard and power

The Control Center opens the native Xfce dialogs for screen resolution, keyboard shortcuts and power/battery behavior. Choose only display modes supported by your laptop screen.

## Performance

The recommended profile keeps compositing and GTK animations disabled for the older Intel/Radeon graphics hardware. The effects profile turns them on; switch back to the smooth profile if the desktop becomes slow or shows visual glitches.

## Full customization

**All system settings** opens Xfce Settings Manager. It includes appearance, icons, fonts, mouse, keyboard, display, window manager and other desktop preferences. These are native Xfce settings, not simulated controls.

With full-root USB persistence enabled, your theme, wallpaper, panel, keyboard and other user preferences are saved across reboots.
